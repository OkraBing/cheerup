# 阶段 0 测试清单：外壳

这一版**没有行情，小人也不会跳舞**。窗口里只有一块占位面板和一个站着不动的小人，外面一圈很淡的虚线是窗口的边界（只有测试版才画，方便看出「透明的地方」有多大）。

要确认的只有一件事：这个小窗在 Windows 上，能不能像 Mac 版那样「悬在角落、不打扰」。

每一项请回「行」或「不行」。不行的，截一张图（尽量把小窗底部那行灰色小字也截进去）。

## 下载和打开

这一版是免安装的，不用装，解压就能跑。

1. 在 Windows 电脑的浏览器里打开 <https://github.com/OkraBing/cheerup/releases/tag/win-shell-test-0.0.1>，点 `CheerUp-windows-shell-test.zip` 下载（不用登录）。也可以从 Mac 上用微信、网盘、U 盘传过去。
2. 在下载好的 zip 上**右键 →「全部解压缩」**，解压到桌面。不要在压缩包里直接双击 exe，那样它找不到旁边的文件。
3. 打开解压出来的 `CheerUp` 文件夹，里面有两个文件：`CheerUp.exe` 和 `WebView2Loader.dll`。两个要放在一起，不要单独挪走 exe。
4. 双击 `CheerUp.exe`。Windows 会弹出蓝色的「Windows 已保护你的电脑」，这是因为程序没有花钱买微软的签名，不是出了问题。点 **更多信息** → **仍要运行**。（传文件时如果杀毒软件或浏览器提示「不常见的文件」，选「保留」或「信任」。）
5. 如果弹出一个框说需要「WebView2」：点它给的链接装上微软的 WebView2 运行库，再双击 `CheerUp.exe`。Windows 11 和更新过的 Windows 10 都自带它，一般不会遇到。

**应该看到**：屏幕右下角出现一个小窗：一圈淡淡的虚线框，框里下半部分是一块深色圆角面板，面板右上沿站着一个白色线条小人，手里两个红色花球。

> 如果什么都没出现：看看右下角托盘（时间旁边，可能收在 `^` 里）有没有 CheerUp 的图标，点一下它。还是没有，就告诉我「打开后什么都没有」。

先请截一张带小窗的图发我，并告诉我是 Windows 10 还是 11。

## 一、悬浮在最上面，点它不抢焦点

| | 做什么 | 应该看到什么 |
|---|---|---|
| 1.1 | 打开记事本，把它最大化 | 小窗还在记事本上面，没有被盖住 |
| 1.2 | 在记事本里打几个字。然后点一下小窗上的小人，再点一下面板上的空白处。不要点回记事本，直接继续打字 | 小人举起了手；接着打的字**仍然出现在记事本里**，记事本的标题栏没有变灰 |
| 1.3 | 看小窗最下面那行灰色小字 | 写着「被激活 0 次」。如果变成红色的「被激活 N 次」，说明它抢了焦点 |

## 二、透明、无边框，透明处能点穿

| | 做什么 | 应该看到什么 |
|---|---|---|
| 2.1 | 看小窗的样子 | 没有标题栏、没有白色或黑色的底。虚线框里、面板以外的地方是透的，能看到后面的东西。面板四个圆角外面没有黑色或白色的尖角 |
| 2.2 | 记事本里多打几行字。把小窗拖到这些字上面（拖法见第七项），让虚线框里的空白处（面板上方、小人左边）压着字。在那块空白处点一下，或者按住拖一下 | 点击落到了记事本上：光标跳到你点的位置，按住拖能选中后面的字。就像小窗那块地方不存在一样 |
| 2.3 | 点小人；点面板上的两个开关 | 小人举手 / 放下；开关变绿 / 变灰。说明有内容的地方点得到 |
| 2.4 | 鼠标慢慢地在面板边缘移进移出几次 | 小窗不闪、不抖、不变黑 |

## 三、不在任务栏和 Alt+Tab 里

| | 做什么 | 应该看到什么 |
|---|---|---|
| 3.1 | 看屏幕底部的任务栏 | 没有 CheerUp 的图标（托盘里那个小图标不算） |
| 3.2 | 按住 Alt 再按 Tab，看弹出来的窗口列表 | 列表里没有 CheerUp |
| 3.3 | 按 Win+Tab 看「任务视图」 | 里面也没有 CheerUp |

## 四、托盘图标

| | 做什么 | 应该看到什么 |
|---|---|---|
| 4.1 | 看屏幕右下角时间旁边（可能收在 `^` 里） | 有 CheerUp 的图标，鼠标停上去显示「CheerUp」 |
| 4.2 | 左键点一下它；再点一下 | 第一下小窗消失，第二下小窗回来 |
| 4.3 | 右键点它 | 弹出一个小菜单：「显示 / 隐藏」和「退出」 |
| 4.4 | 点「退出」 | 小窗和托盘图标都没了。然后再双击 `CheerUp.exe` 打开，继续后面的测试 |

## 五、快捷键和开机启动

| | 做什么 | 应该看到什么 |
|---|---|---|
| 5.1 | 按 Ctrl+Alt+S；再按一次 | 小窗隐藏；再按回来 |
| 5.2 | 在记事本里打字的时候按两次 Ctrl+Alt+S，然后继续打字 | 小窗隐藏又回来，字仍然打在记事本里 |
| 5.3 | 小窗底部小字里的「快捷键」 | 后面是 ✓。如果是红色的 ✗，说明这个组合键被别的软件占了，告诉我是哪个软件（常见的是输入法、截图工具） |
| 5.4 | 打开面板上的「开机启动」开关，然后重启电脑并登录 | 登录后小窗自己出现，开关还是绿的 |
| 5.5 | 关掉「开机启动」开关，再重启一次 | 这次小窗没有自己出现。然后手动打开它继续 |

> 5.4 和 5.5 要重启两次，可以放到最后做。

## 六、截图和屏幕共享里不显示

| | 做什么 | 应该看到什么 |
|---|---|---|
| 6.1 | 开关关着的时候，按 Win+Shift+S 截一张带小窗的图 | 截图里有小窗 |
| 6.2 | 打开「截图和屏幕共享里不显示」开关，再截一张同样位置的图 | 屏幕上小窗还在，但**截图里没有它**，那块地方是后面的桌面或窗口。（如果截图里是一块黑色方块，也请告诉我，那是系统版本比较老的表现） |
| 6.3 | 有条件的话，开一个腾讯会议 / 飞书的屏幕共享，看共享预览 | 预览里没有小窗 |
| 6.4 | 关掉开关再截一张 | 截图里又有小窗了 |

## 七、拖动和记住位置

| | 做什么 | 应该看到什么 |
|---|---|---|
| 7.1 | 按住面板上的空白处（不是按钮），拖到屏幕别的地方 | 小窗跟着鼠标走，不卡、不甩在后面太远；拖的时候记事本没有失去焦点 |
| 7.2 | 松手后点面板上的「退出」，再双击 `CheerUp.exe` 打开 | 小窗出现在刚才拖到的位置，而不是回到右下角 |
| 7.3 | 点面板上的「隐藏」 | 小窗消失；用托盘图标或 Ctrl+Alt+S 能叫回来 |

## 顺便留意

这些不算在六项里，但看到了请一并告诉我：

- 文字和小人的线条清不清晰，有没有发虚、锯齿，或者线条边上有一圈黑边 / 白边。
- 全屏看视频或全屏放 PPT 时，小窗是还在上面，还是被盖住了（两种都可以接受，我想知道是哪种）。
- 如果有两块屏幕：把小窗拖到另一块屏幕上，大小和清晰度正不正常。

## 怎么卸载

先把「开机启动」关掉，点「退出」，然后直接删掉整个 `CheerUp` 文件夹。它记的位置存在 `%APPDATA%\local.cheerup` 里，想删也可以一起删。
